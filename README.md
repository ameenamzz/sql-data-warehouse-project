# 🚀 Data Warehouse and Analytics Project

Welcome to my **Data Warehouse and Analytics Project** repository!

This project demonstrates an end-to-end data warehousing and analytics solution, starting from raw source data and building a structured data warehouse to generate meaningful business insights.

The project is designed as a portfolio project to demonstrate practical skills in **SQL, Data Warehousing, Data Cleaning, Data Modeling, Exploratory Data Analysis, and Business Analytics**.

---

## 📌 Project Overview

The project is divided into two major parts:

1. **Data Engineering — Building the Data Warehouse**
2. **Data Analytics — Generating Business Insights**

The overall workflow is:

```text
ERP & CRM CSV Files
        ↓
    Data Loading
        ↓
    Data Cleaning
        ↓
   Data Integration
        ↓
  Data Warehouse
        ↓
   SQL Analytics
        ↓
 Business Insights
